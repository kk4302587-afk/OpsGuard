# OpsGuard 答辩 PPT 大纲

---

## 第一页：封面
- 项目名称：OpsGuard — 智能运维 Agent
- 副标题：基于 MCP 协议的安全可控 AI 运维助手
- 团队信息

---

## 第二页：问题背景（1分钟）
- 传统运维痛点：命令复杂、门槛高、易误操作
- 场景举例：管理员说"帮我清理系统垃圾"，传统方式需要 5+ 条命令
- 核心挑战：AI 推理不可控 → 如何让 AI 安全地操作生产系统？

---

## 第三页：解决方案概览（1分钟）
- 一句话：自然语言 → 安全校验 → 智能推理 → 人类审批 → 安全执行 → 结果验证
- 架构图（三层：前端 / 后端 / OS 层）
- 关键词：MCP 协议、三层安全护栏、最小权限、推理链路溯源

---

## 第四页：系统演示（3-4分钟）
### Demo 1：磁盘空间清理
- 输入："磁盘快满了，帮我分析一下"
- 展示：Agent 调用工具 → 定位大文件 → 判断是否关键 → 请求确认 → 清理 → 验证

### Demo 2：安全攻防
- 切换到安全演示页面
- 尝试注入攻击 → 展示三层拦截
- 尝试正常请求 → 正常放行

### Demo 3：健康巡检
- 一键生成报告 → 展示四维检测结果 → 导出 PDF

---

## 第五页：核心技术 - MCP 工具层（1分钟）
- 32 个原子化工具，6 大类别
- 工具设计原则：原子化 + 少量聚合，Agent 自由组合
- 风险分级：READ / WRITE / DESTRUCTIVE
- 代码示例：@mcp.tool() 装饰器

---

## 第六页：核心技术 - 安全护栏（2分钟）
- 三层纵深防御架构图
- 第一层：规则引擎（71条，0ms）
- 第二层：BERT 分类器（DeBERTa ONNX，30ms，语义级）
- 第三层：LLM System Prompt（始终生效）
- 附加：高危意图检测（警告不拦截）
- 自适应降级：低配环境自动退回两层
- 数据：测试 18 个用例，零误判

---

## 第七页：核心技术 - Agent 引擎（1分钟）
- LangGraph 图式编排
- Plan → Approve → Execute → Verify 闭环
- WebSocket 实时审批等待
- 多轮工具调用（最多 10 轮）
- 执行后自动验证

---

## 第八页：核心技术 - 最小权限（1分钟）
- opsguard 专用系统用户
- sudoers 白名单（只允许特定命令）
- 受保护路径列表
- 写操作前自动备份 + 回滚能力
- 命令超时限制

---

## 第九页：创新亮点（1分钟）
1. 故障关联图谱 — 动态构建实体关系，可视化根因链路
2. 知识自动沉淀 — 从历史中学习，越用越聪明
3. 操作影响预评估 — 执行前分析影响范围
4. 诊断进度可视化 — 用户实时看到 Agent 在做什么
5. 安全攻防演示 — 评委可直接试玩

---

## 第十页：技术选型（30秒）
- 表格：前端/后端/大模型/安全/存储
- 强调国产化：Qwen3 + Ant Design + ECharts + 麒麟 V11

---

## 第十一页：部署与运行（30秒）
- 一键部署：bash scripts/install.sh
- systemd 服务管理
- 支持 LoongArch + 麒麟 V11

---

## 第十二页：总结与展望（30秒）
- 已实现：全部基础功能 + 7 项创新功能
- 未来方向：多节点支持、模型本地化部署、更多工具插件
- 一句话总结：OpsGuard 让运维人员用自然语言安全高效地管理 Linux 系统
